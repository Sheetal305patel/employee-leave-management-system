# Employee Leave Management System

A web-based Employee Leave Management System developed using Django, Python, and SQL to automate employee leave requests, approval workflows, and leave tracking.

---

## Features

- Employee Leave Application Form
- Leave Request Management
- Admin Dashboard
- Approve / Reject Leave Requests
- Leave Status Tracking
- Database Integration
- Professional Responsive UI
- Django Authentication System

---

## Tech Stack

### Backend
- Python
- Django

### Database
- SQLite
- SQL

### Frontend
- HTML
- CSS

## Installation

### Clone Repository

```bash
git clone YOUR_GITHUB_LINK
```

---

### Move to Project Folder

```bash
cd leave-management
```

---

### Create Virtual Environment

```bash
python -m venv venv
```

---

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

---

### Install Django

```bash
pip install django
```

---

## Run Project

```bash
python manage.py runserver
```

Open:

```bash
http://127.0.0.1:8000
```

---

## Admin Panel

```bash
http://127.0.0.1:8000/admin
```
